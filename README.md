## English

Brazilian Portuguese fan translation of *Maid Cafe on Electric Street*. The translated text replaces the game's English text directly in `resources.assets`. No mod loader is required.

### Repository layout

```
translations/          ← WHERE TRANSLATION HAPPENS (edit only the "PT" field)
  texts/               menus, names, items, short NPC lines
  scenes/              story dialogue (one scene per file)
  extras/              random NPC lines, CG gallery, credits
tools/maidloc/         extract / sync / patch tool (Go)
resources/             reference generated by extract, do not edit by hand
  extracted/           every original JSON from the game (languages/, scenes/, data/)
  map.json             asset map: languages, format, fields, text counts
```

### Translation file format

Every game text has the **English original** (`EN`) and a slot for the **Portuguese** (`PT`):

```json
"StartNewGame": {
  "PT": "Novo Jogo",
  "EN": "New Game"
},
```

In scenes, each line also shows who is speaking, to help keep the voice consistent:

```json
"1": {
  "Personagem": "Miyu",
  "PT": "",
  "EN": "Hiii! One meat bun please!"
},
```

- **Edit only `PT`.** Do not change `EN`, `Personagem` (speaker), or the keys (`"1"`, `"StartNewGame"`).
- An empty `PT` means "not translated yet". In game, that text stays in English.
- `(narração)` (narration) and `(protagonista)` (protagonist) are speakers with no on-screen name. A few speakers still show the game's internal code (for example, `suinaixiang`).

### Translation rules

1. **Keep the markup.** The patcher warns when it doesn't match the English.
   - `{0}` and `{1}` are values the game inserts. Example: `"earn [{0}] yen"` → `"ganhar [{0}] ienes"`.
   - `<color=blue>text</color>` is a color tag. Keep the tags and translate only the text between them.
   - `\n` is a line break. Keep about the same number, because the dialogue box has a fixed width.
2. **Valid JSON.** Quotes inside a text become `\"`. Don't delete commas or braces. If a file breaks, the patcher shows the file and line of the error.
3. **Save as UTF-8.** Accented characters are fine.
4. **Menu texts have little room.** Prefer short versions.
5. **Use the same names and terms everywhere** (Shiro, Miyu, Favna, Senpai, Kohai...). The `Personagem` field and `texts/textdata_en.json` are the reference.

### The `maidloc` tool

Requires Go. Run it from the repository root:

```
go run ./tools/maidloc <command>
```

To skip compiling on every run, build an executable: `go build -o maidloc.exe ./tools/maidloc` (`.exe` files are git-ignored).

| Command | What it does |
|---|---|
| `status` | Shows translation progress per file and per folder (`-v` lists every file). |
| `patch` | Reads the `PT` field from `translations/` and writes it into the right game assets and keys. Without `-apply`, it only does a dry run and prints warnings. |
| `extract` | Reads the game and regenerates `resources/extracted/` and `resources/map.json`. Only needed after a game update. |
| `sync` | Creates or updates the files in `translations/` from `resources/extracted/`. **Keeps all existing PT.** If the English of a translated text changed, it flags it as `REVISAR` (review). |

Common options: `-game "<*_Data folder>"`, if the game isn't in the default Steam folder, and `-dir <folder>` to use another translations folder.

#### Testing the translation in game

```
go run ./tools/maidloc patch            # dry run: lists what would be applied, plus warnings
go run ./tools/maidloc patch -apply     # writes to the game (close the game first)
```

Then start the game with the **English** language selected.

How the patch works:
- It always starts from the **original** file, `resources.assets.bak`, which is created on the first apply. You can run it as many times as you like: the file doesn't grow and old translations don't pile up.
- Only texts with a filled-in `PT` change. Everything else stays identical to the original (verified).
- **To undo:** copy `resources.assets.bak` over `resources.assets`, or use "Verify integrity of game files" in Steam.

#### When the game updates

1. In Steam, run "Verify integrity" to get a clean file, then delete the old `resources.assets.bak`.
2. `go run ./tools/maidloc extract`
3. `go run ./tools/maidloc sync`: review the texts flagged `REVISAR` (English changed) and `ÓRFÃ` (text removed from the game).
4. `go run ./tools/maidloc patch -apply`

### How it works

The game stores its texts as JSON TextAssets inside `resources.assets`, in two formats (details in `resources/map.json`):

- **Per language** (`format: dict`): one asset per language (`ui_cn`, `ui_jp`, `ui_en`, `ui_tc`), each shaped as `{key: text}`. We translate the `*_en` asset.
- **Per row** (`format: rows`): one asset with every language on each row (`StoryText`=cn, `JP`, `EN`, `TC`; or `CnText`/`JpText`/`EnText`/`TcText`; or `LKName`/`JpName`/`EnName`). We translate the English field.

`patch` reads the original asset, replaces the English field with `PT` for each filled-in key, writes the asset at the end of `resources.assets`, and points the object table at the new asset.

## Português (Brasil)

Tradução não oficial de *Maid Cafe on Electric Street* para o português do Brasil. O texto traduzido substitui o inglês direto no `resources.assets`. Não é preciso instalar mod nem BepInEx.

### Estrutura do repositório

```
translations/          ← ONDE SE TRADUZ (edite só o campo "PT")
  texts/               menus, nomes, itens, falas curtas de NPC
  scenes/              diálogos da história (uma cena por arquivo)
  extras/              falas aleatórias, galeria de CGs, créditos
tools/maidloc/         ferramenta de extração / sincronização / patch (Go)
resources/             referência gerada pelo extract, não se edita à mão
  extracted/           todos os JSON originais do jogo (languages/, scenes/, data/)
  map.json             mapa dos assets: idiomas, formato, campos, nº de textos
```

### Como estão os arquivos de tradução

Cada texto do jogo aparece com o **original em inglês** (`EN`) e o espaço para o **português** (`PT`):

```json
"StartNewGame": {
  "PT": "Novo Jogo",
  "EN": "New Game"
},
```

Nas cenas, cada fala também mostra quem está falando, para ajudar na coerência:

```json
"1": {
  "Personagem": "Miyu",
  "PT": "",
  "EN": "Hiii! One meat bun please!"
},
```

- **Edite só o `PT`.** Não altere `EN`, `Personagem` nem as chaves (`"1"`, `"StartNewGame"`).
- `PT` vazio quer dizer "ainda não traduzido". No jogo, esse texto continua em inglês.
- Personagens marcados como `(narração)` e `(protagonista)` não têm nome na tela. Alguns ainda aparecem com o código interno do jogo (por exemplo, `suinaixiang`).

|---|---:|---:|---|
| `translations/texts/` | 4 | 2.992 | `ui_en` (menus, 860), `textdata_en` (nomes, itens, pratos, 1.131), `dialogue_en` (falas curtas de NPC, 973), `charactername_en` (28) |
| `translations/scenes/` | 49 | 7.394 | Diálogos da história. Os maiores são `Dialogue02_Operat_Lobby` (1.360), `Dialogue03_Operat_RestRoom` (725), `Dialogue41_OsakaCastlePark` (643), `Dialogue05_Shrine` (575) e `Dialogue21_Cinema_Indoor` (544) |
| `translations/extras/` | 4 | 592 | `RamdomNpcDiaText` (falas aleatórias, 250), `DevelopmentReport` (créditos, 239), `GameCG` (nomes das CGs, 91), `InterActionDialogue` (12) |

Prioridade sugerida: `texts/ui_en.json` → `texts/textdata_en.json` → `texts/dialogue_en.json` → `scenes/` → `extras/`.

Não estão incluídos: `QuestionData` (quiz) e `LineMessage`. Esses dois só têm texto em chinês no jogo, e ainda não sabemos de onde vem a versão em inglês.

### Regras de tradução

1. **Preserve a marcação.** O patcher avisa quando ela não confere com o inglês.
   - `{0}`, `{1}` são valores que o jogo insere. Exemplo: `"earn [{0}] yen"` → `"ganhar [{0}] ienes"`.
   - `<color=blue>texto</color>` é uma tag de cor. Mantenha as tags e traduza só o texto entre elas.
   - `\n` é quebra de linha. Mantenha uma quantidade parecida, porque a caixa de diálogo tem largura fixa.
2. **JSON válido.** Aspas dentro do texto viram `\"`. Não apague vírgulas nem chaves. Se o arquivo quebrar, o patcher mostra o arquivo e a linha do erro.
3. **Salve em UTF-8.** Acentos são permitidos normalmente.
4. **Textos de menu têm pouco espaço.** Prefira versões curtas.
5. **Use os mesmos nomes e termos em tudo** (Shiro, Miyu, Favna, Senpai, Kohai...). O campo `Personagem` e `texts/textdata_en.json` são a referência.

### Ferramenta `maidloc`

Requer Go. Rode da raiz do repositório:

```
go run ./tools/maidloc <comando>
```

Para não compilar a cada execução, gere um executável: `go build -o maidloc.exe ./tools/maidloc` (o `.exe` é ignorado pelo git).

| Comando | O que faz |
|---|---|
| `status` | Mostra quanto já foi traduzido, por arquivo e por pasta (`-v` lista todos os arquivos). |
| `patch` | Lê o campo `PT` de `translations/` e grava nos arquivos e chaves certos do jogo. Sem `-apply`, só testa e mostra os avisos. |
| `extract` | Lê o jogo e regenera `resources/extracted/` e `resources/map.json`. Só é necessário quando o jogo for atualizado. |
| `sync` | Gera ou atualiza os arquivos de `translations/` a partir de `resources/extracted/`. **Mantém todo o PT já feito.** Se o inglês de algum texto traduzido mudou, marca como `REVISAR`. |

Opções comuns: `-game "<pasta *_Data>"`, se o jogo não estiver na pasta padrão da Steam, e `-dir <pasta>` para usar outra pasta de traduções.

#### Testar a tradução no jogo

```
go run ./tools/maidloc patch            # teste: lista o que será aplicado e os avisos
go run ./tools/maidloc patch -apply     # grava no jogo (feche o jogo antes)
```

Depois, abra o jogo com o idioma **English**.

Como o patch funciona:
- O patch sempre parte do arquivo **original**, o `resources.assets.bak`, que é criado na primeira aplicação. Pode rodar quantas vezes quiser: o arquivo não cresce e traduções antigas não se acumulam.
- Só os textos com `PT` preenchido mudam. Todo o resto continua idêntico ao original (isso foi verificado).
- **Para desfazer:** copie `resources.assets.bak` por cima de `resources.assets`, ou use "Verificar integridade dos arquivos" na Steam.

#### Quando o jogo atualizar

1. Na Steam, use "Verificar integridade" para garantir um arquivo limpo e apague o `resources.assets.bak` antigo.
2. `go run ./tools/maidloc extract`
3. `go run ./tools/maidloc sync`: confira os textos marcados como `REVISAR` (inglês mudou) e `ÓRFÃ` (texto removido do jogo).
4. `go run ./tools/maidloc patch -apply`

### Como funciona por dentro

O jogo guarda os textos como TextAssets JSON dentro de `resources.assets`, em dois formatos (detalhes em `resources/map.json`):

- **Por idioma** (`format: dict`): um asset por língua (`ui_cn`, `ui_jp`, `ui_en`, `ui_tc`), cada um no formato `{chave: texto}`. Traduzimos o `*_en`.
- **Por linha** (`format: rows`): um asset com todas as línguas em cada linha (`StoryText`=cn, `JP`, `EN`, `TC`; ou `CnText`/`JpText`/`EnText`/`TcText`; ou `LKName`/`JpName`/`EnName`). Traduzimos o campo inglês.

O `patch` lê o asset original, troca o campo inglês pelo `PT` em cada chave preenchida, grava o asset no fim do `resources.assets` e aponta a tabela de objetos para o asset novo.
