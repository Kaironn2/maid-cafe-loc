# AGENTS.md

Fan translation of Maid Cafe on Electric Street into Brazilian Portuguese. The translated text replaces the game's English text inside `resources.assets`.

## Where things are

- `translations/`: the files people translate. Each entry has `PT` (translation) and `EN` (original). Only `PT` is edited.
  - `texts/`: UI, item and character names, short NPC lines.
  - `scenes/`: story dialogue, one scene per file.
  - `extras/`: random NPC lines, CG names, credits.
  - `glossary.md`: how recurring terms are translated. Read it before translating.
- `tools/maidloc/`: Go tool. `extract` reads the game, `sync` updates `translations/`, `status` shows progress, `patch` writes PT into the game.
- `tools/check/`: validators. `check.js` checks translation files, `check-md.js` checks text file encoding.
- `tools/translation-rules.md`: rules for translating (encoding, format, consistency, tone).
- `resources/`: original game data generated by `extract`. Do not edit by hand.

## Rules

- Files are UTF-8 without BOM, with real accented characters.
- Keep `{0}`, `<color>` tags and `\n` exactly as in the English text.
- Run `node tools/check/check.js <file>` after editing a translation file.
- Run `go run ./tools/maidloc patch` (dry run) to confirm there are no warnings.
