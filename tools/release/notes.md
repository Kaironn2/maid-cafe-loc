Tradução PT-BR de *Maid Cafe on Electric Street*, feita por fãs.

## Download

| Sistema | Arquivo |
|---|---|
| Windows | `MaidCafe-PTBR-<versão>-windows-x64.zip` |
| Linux / Steam Deck (Proton) | `MaidCafe-PTBR-<versão>-linux-x64.zip` |
| macOS com Apple Silicon (CrossOver/Whisky) | `MaidCafe-PTBR-<versão>-macos-arm64.zip` |
| macOS com Intel (CrossOver/Whisky) | `MaidCafe-PTBR-<versão>-macos-x64.zip` |

## Como instalar

1. Feche o jogo.
2. Extraia o `.zip` e abra o `MaidCafe-PTBR`.
3. O instalador acha o jogo na Steam sozinho. Se não achar, abre uma janela para você escolher a pasta do jogo.

O `LEIA-ME.txt` dentro do zip explica cada sistema, o aviso do Windows SmartScreen e como desinstalar.
